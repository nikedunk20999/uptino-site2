# Уптинские деликатесы

Статическая витрина для GitHub Pages. Основной исходник — эта папка `outputs/uptino`. Промежуточную копию `work/github-site` не редактировать отдельно.

## Структура

- `index.html` — разметка магазина и диалогов.
- `assets/catalog.js` — единственный исходный каталог: 32 товара, цены и единицы продажи из прайса от 04.11.2026. Общий для магазина и демо-редактора.
- `assets/core.js` — расчёт корзины в граммах и копейках, проверка минимума 5 000 ₽, нормализация данных и работа с хранилищем.
- `assets/shop.js` — карточки, фильтры и управление корзиной. Значения выводятся через `textContent`, без вставки пользовательского HTML.
- `assets/delivery.js` — выбор региона/города при первом визите и изменение из корзины.
- `assets/shop.css` — стили магазина с единственным блоком на каждый брейкпоинт.
- `admin-demo.html`, `assets/admin.js`, `assets/admin.css` — открытая демонстрация редактора, изменения только в браузере.
- `tests/core.test.cjs` — проверки цен, веса, границ минимального заказа, сохранённых данных и телефона. Запуск: `node --test tests/core.test.cjs`.

Скрипты подключены через `defer` в явном порядке. Сборщик и сервер для просмотра не требуются; можно открыть `index.html` локально. Для общего доступа используется GitHub Pages.

## Что сохраняется

Корзина: стабильный идентификатор товара и запрошенный вес в граммах (либо количество упаковок). Цены берутся заново из общего каталога. Сумма — предварительная, окончательный вес и фасовку подтверждает менеджер. Для трёх нарезок единица продажи в прайсе не указана: их цены не включаются в расчёт минимального заказа.

Регион и населённый пункт сохраняются локально на устройстве. Имя, телефон и email из формы не сохраняются скриптами и не отправляются. При недоступном хранилище интерфейс продолжает работать.

## Границы текущей версии

Это витрина и демонстрация корзины. Отправка заказа, письма, приём оплаты, настоящая авторизация администратора и серверное сохранение товаров не подключены. Кнопка оформления остаётся недоступной.

Кнопка карты открывает официальную карту СДЭК в отдельной вкладке. Встроенный выбор ПВЗ и стоимость доставки пока не подключены. Для официального виджета нужны ключ Яндекс.Карт с ограничением по домену и серверный прокси с API-данными СДЭК. Секрет СДЭК нельзя помещать в эти публичные файлы. Документация: https://github.com/cdek-it/widget/wiki/Установка-4.0

Будущий сервер должен заново проверять актуальные цены, единицы, наличие, минимум заказа и параметры доставки. Клиентский расчёт не является проверкой для реального приёма заказов.
